Network fundamentals reference

Core architectural principles governing subnet addressing, resolution protocols, and flow control.

Subnet masks and CIDR notation?

Subnet masks partition 32-bit IPv4 addresses into network and host components. A /24 subnet designates 24 prefix bits for network routing, leaving 8 bits for 254 unique assignable host addresses.

Address Resolution Protocol mechanism?

ARP binds Layer 3 IP datagrams to physical Layer 2 MAC addresses. Devices broadcast ARP requests across the local Ethernet collision domain and cache unicast replies in local kernel tables.

Recursive versus iterative DNS queries?

Recursive resolvers accept client requests and traverse the hierarchical domain tree from root hints down to authoritative nameservers, caching resolved resource records until TTL expiration.

TCP three-way handshake sequence?

Transmission Control Protocol synchronizes sequence numbers through SYN, SYN-ACK, and ACK transmissions, establishing reliable byte-stream ordering and window buffer agreements before transmitting data.

Interarrival jitter calculation?

Per RFC 3550, jitter measures the statistical variance of packet arrival intervals compared to transit delays. High jitter degrades real-time applications such as voice calls and video streaming.

TTL hop limits and routing loops?

The Time-to-Live field decrements by one at every Layer 3 forwarding router. When TTL hits zero, routers drop the packet and emit an ICMP Time Exceeded message, preventing infinite routing loops.
